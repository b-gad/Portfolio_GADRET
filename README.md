# Portfolio — Benoît Gadret

Portfolio personnel présentant mon parcours académique, mes expériences, mes projets et mes centres d'intérêt, réalisé dans le cadre de mes candidatures de master aux États-Unis.

Site statique en HTML/CSS/JavaScript, sans dépendance de build.

## Structure

- `index.html` — page unique (contenu, styles et scripts)
- `rugby/`, `corbin/`, `montagne/`, `nepal/`, `CCE/`, `stage/` — photos par rubrique
- `pdf-thumbs/` — vignettes des rapports PDF
- `*.pdf` — CV et rapports de projets/stage

## Aperçu local

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec un petit serveur local, par exemple :

```bash
python3 -m http.server 8000
```
